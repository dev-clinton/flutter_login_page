# CEE – Personal Account Application

CEE is a simple Flutter-based account management application developed as a student project.

## Features
- User registration
- User login and logout
- Password hashing
- Local account storage
- Clean and simple user interface

## Technologies Used
- Flutter
- Dart
- SQLite
- Cryptography
